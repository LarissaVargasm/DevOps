# DevOps

Repositório destinado às atividades e projetos desenvolvidos na disciplina de **DevOps** da faculdade.

## 📌 Descrição

Este repositório será utilizado para organizar e armazenar as atividades, exercícios e projetos desenvolvidos durante a disciplina.

## 🎯 Objetivo

Aplicar na prática conceitos relacionados à cultura DevOps, automação, integração e entrega contínua, controle de versões e ferramentas utilizadas no desenvolvimento e gerenciamento de software.

## 🛠️ Tecnologias e ferramentas

As tecnologias e ferramentas utilizadas serão adicionadas conforme o desenvolvimento das atividades da disciplina.
